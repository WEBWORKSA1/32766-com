Why bytes matter more than characters

A field that holds “1,000 characters” of English may hold only 333 characters of Japanese, and far fewer emoji. Storage engines, network protocols and indexes allocate by bytes, so a limit written in bytes behaves very differently across languages. When a value goes over, you get errors like Lucene's bytes can be at most 32766 in length, PostgreSQL's index row size exceeds btree maximum, or silently truncated data.

The 32,766-byte line

Apache Lucene, the library inside Elasticsearch, OpenSearch and Solr, refuses any single indexed term longer than 32,766 bytes. A keyword field stores the whole value as one term, so a long description or a base64 blob mapped as keyword triggers the error. The meter above turns red when your text crosses that line. FAQ

How many bytes is an emoji?

A single emoji is usually 4 bytes in UTF-8. Emoji with skin tones, gender signs or family combinations are several emoji joined with invisible zero-width joiners — 👩🏽‍💻 is 15 bytes.

How do I count bytes in code?

JavaScript: new TextEncoder().encode(s).length. Python: len(s.encode('utf-8')). Java: s.getBytes(StandardCharsets.UTF_8).length. SQL (MySQL): OCTET_LENGTH(col); PostgreSQL: octet_length(col).

Is MySQL's utf8 the same as UTF-8?

No. MySQL's legacy utf8 (utf8mb3) stores at most 3 bytes per character and cannot store emoji. Use utf8mb4, and remember it can use 4 bytes per character when you size columns and indexes.
