Excel's 32,767-character cell limit

One cell, 32,767 characters — 215−1, one more than this site's namesake. Exports that ignore it produce truncated data or files Excel says are damaged.

32766.com editorial · Updated November 19, 2026 · 5-minute read

Symptoms

  • Pasted or imported text silently cut off at 32,767 characters.
  • “We found a problem with some content…” when opening an .xlsx written by a script.
  • Libraries throwing errors when setting a cell value over the limit.
  • CSV opened in Excel: long fields truncated or spilling into the next row.

How Excel counts

The limit applies to what LEN() returns — UTF-16 code units — so each emoji uses 2 of your 32,767. Older versions show only the first 1,024 characters in the cell itself even when more are stored; the formula bar shows the rest.

Fixes

  1. Split across cells or rows. Chunk the value into ≤32,767-character parts (the splitter has an Excel preset) and recombine with TEXTJOIN or CONCAT when needed.
  2. Truncate intentionally. If the full value isn't needed, cut to ~32,000 and add a marker such as “[truncated]” so nobody mistakes it for complete data.
  3. Keep long text out of the sheet. Store it in a file, database or document and put a link or ID in the cell.
  4. Validate in code before writing. In Python: len(s.encode('utf-16-le')) // 2 <= 32767. Several .xlsx libraries already enforce the limit — check yours.
  5. Use Power Query or a database for analysis of large text fields instead of the grid.
