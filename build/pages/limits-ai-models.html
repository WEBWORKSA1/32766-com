AI & LLM token limits

Language models measure everything in tokens: your system prompt, the conversation so far, retrieved documents, tool definitions and the answer. The context window is the total that fits in one request. Output caps are usually much smaller than windows. Because models and limits change monthly, this hub lists durable tiers and rules of thumb rather than a model-by-model table that would be stale next week.

Budgeting a request

Window ≥ system prompt + tools + history + retrieved context + your question + the maximum answer you allow. Reserve the answer first, keep a 10–20% margin, and don't assume quality stays flat as you approach the limit. Read the full guide.

FAQ

How many tokens is 1,000 words?

Roughly 1,300–1,400 tokens for English prose.

Is the context window input-only?

Usually it's input plus output combined; some providers list separate input and output limits. Check the model card.

Why does my non-English text use more tokens?

Tokenizers are trained mostly on English, so other languages split into more, smaller pieces.
