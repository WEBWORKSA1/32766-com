Spreadsheets, files & systems

Many system limits cluster around powers of two, and 32,767 (215−1, the largest signed 16-bit integer) shows up again and again: Excel's per-cell character limit, Windows' extended path length, Oracle's extended VARCHAR2 and the top of Kubernetes' default NodePort range. Its neighbor 32,766 is Lucene's term limit — and this site's name.

Excel and Google Sheets

An Excel cell holds 32,767 characters, counted like LEN() (UTF-16 units, so emoji count as 2). Exports that exceed it — common with JSON, logs and long descriptions — produce corrupted or truncated files. Split long values with the text splitter's Excel preset. Google Sheets allows 50,000 characters per cell and 10 million cells per spreadsheet.

Paths and file names

Classic Windows paths stop at 260 characters unless long-path support is enabled; most file systems cap a single name at 255 (Linux ext4 counts bytes, so 255 bytes of UTF-8).

FAQ

What happens if I paste more than 32,767 characters into an Excel cell?

Excel truncates it to 32,767 characters. Libraries writing .xlsx files may throw an error or produce a file Excel reports as damaged.

Why does 32,767 appear so often?

It's the largest value of a signed 16-bit integer, a common size for length fields in older formats and APIs.

What is the default Kubernetes NodePort range?

30000–32767, which gives 2,768 ports.
