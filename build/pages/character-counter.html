How this character counter counts

Most people mean visible characters when they say “characters”: each letter, digit, space, punctuation mark or emoji you can see counts once. This tool counts those using your browser's grapheme segmentation, so a family emoji like 👨‍👩‍👧 (five code points joined together) counts as one character — the way you perceive it.

Not every system agrees. X counts most emoji and CJK characters as two. LinkedIn and many schedulers count UTF-16 code units, where an emoji is also two. Databases and APIs often limit bytes, and in UTF-8 an emoji takes four. That's why the panel above shows several counts, and why the “Where does it fit?” list uses the right method for each platform.

Characters with vs. without spaces

“Characters without spaces” removes every whitespace character — spaces, tabs and line breaks. Some translation agencies, academic journals and form fields use it. Social platforms count spaces.

Line breaks count too

A line break is a character. On Windows-origin text a break can be two (carriage return + line feed). If a field is tight, the text cleaner can remove extra breaks and spaces.

FAQ

Do emoji count as one character?

Visually, yes, and this counter shows them as one. On X an emoji counts as 2, in UTF-16 systems (LinkedIn, JavaScript, Excel) usually 2, and in UTF-8 bytes typically 4. See characters vs bytes.

Does a URL count against my X limit?

Every link counts as 23 characters on X regardless of its real length, because X wraps it with its link shortener. The X weighted count above applies that rule.

Can I count characters in Excel or Google Sheets?

Use =LEN(A1). It counts UTF-16 units, so emoji count as 2. Excel cells hold up to 32,767 characters; Google Sheets cells up to 50,000.
