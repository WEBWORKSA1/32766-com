SMS marketing

How SMS segments are billed

Text messages are billed per segment, and a single character can change how many segments you send. Here are the numbers that matter.

32766.com editorial · Updated November 19, 2026 · 6-minute read

Encoding1 segment2 segments3 segmentsEach extra
GSM-7≤160≤306≤459+153
UCS-2≤70≤134≤201+67

Why 160 and 70?

An SMS carries 140 bytes of payload. GSM-7 packs each character into 7 bits: 140 × 8 ÷ 7 = 160 characters. UCS-2 uses 16 bits per character: 140 ÷ 2 = 70. When a message is too long, it's split and each part carries a small User Data Header so phones can reassemble it — leaving 153 GSM-7 or 67 UCS-2 characters per part.

The emoji (and smart-quote) trap

GSM-7 has English letters, digits, common punctuation and some Western European accents. Emoji, curly quotes (“ ” ‘ ’), en and em dashes (– —), the ellipsis character (…) and most non-Latin scripts aren't in it. One such character switches the entire message to UCS-2.

Worked example: a 140-character promo is 1 GSM-7 segment. Add “🎉” and it becomes 142 UCS-2 units (the emoji counts as 2) → 3 segments. Sent to 25,000 subscribers at $0.008 per segment, that's $600 instead of $200.

Extension characters count double

In GSM-7, these characters need an escape code and count as 2: ^ { } \ [ ] ~ | €. A message of 155 regular characters plus two “€” is 159 — still one segment, but close.

Checklist for one-segment messages

  1. Draft in plain text, not a word processor.
  2. Run the text through the SMS counter and fix highlighted characters.
  3. Shorten links with a branded short domain.
  4. Keep required compliance text (e.g. opt-out wording) in the budget.
  5. Use emoji only where they justify the 2–3× cost.
